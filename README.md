# 🚀 shamsrupak.lovable.app

My personal portfolio website — built with React, TypeScript, and Tailwind CSS.

**🔗 Live:** [shamsrupak.lovable.app](https://shamsrupak.lovable.app)

## Tech Stack

- **React** + **TypeScript** — component architecture
- **Tailwind CSS** + **shadcn/ui** — styling & UI primitives
- **Vite** — build tooling
- **Lovable** — AI-assisted development & hosting

## Features

- Dark theme with purple accent design system
- Animated terminal typewriter effect in hero section
- Interactive experience timeline
- Project showcase cards with tech badges
- Responsive across all devices
- Scroll-triggered section animations

## Local Development

```sh
git clone https://github.com/ShamsRupak/shams-rupak-ai-engineer.git
cd shams-rupak-ai-engineer
npm i
npm run dev
```
